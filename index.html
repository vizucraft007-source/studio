Channel Studio Uploader

Channel Studio Uploader is a small personal desktop tool. It runs only on its owner's own computer and is used to manage the owner's own YouTube channels: it uploads finished videos, schedules their publication, sets titles, descriptions, thumbnails, captions and playlists, and reads the channels' own YouTube Analytics so the owner can see how the videos perform.

The tool is not a public service. It has no server, no user accounts and no third-party users. All data stays on the owner's computer.
